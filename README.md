# 基于 Spring Boot 的 AI 心理健康服务系统

> 面向高校学生心理健康支持场景的前后端分离系统，提供 **AI 对话陪伴、情绪记录与分析、心理健康知识科普、后台运营管理** 四类能力。

系统以对话内容与用户自评数据为输入，通过大模型完成情绪识别，结合规则引擎进行风险分级，对高风险用户给出求助指引，并为管理人员提供情绪趋势、会话活跃度等数据看板。

⚠️ **系统定位为情绪支持与心理健康知识服务工具，不提供医学诊断与治疗建议**，所有对话页面与报告页面均附带免责声明及心理援助热线提示。

## 一、功能特性

系统共划分 **10 个功能模块、50 个功能点**（P0 级 32 个、P1 级 13 个、P2 级 5 个）。

### 角色与权限

| 角色 | 说明 | 主要权限 |
| --- | --- | --- |
| 普通用户 | 在校学生，自助注册 | AI 对话、情绪日志、知识浏览、个人会话管理 |
| 管理员 | 心理健康中心教师或运营人员 | 数据看板、文章管理、咨询记录、情绪日志、风险预警处理 |

### 用户端

| 功能 | 说明 |
| --- | --- |
| 注册 / 登录 / 退出 | 账号密码登录，JWT 签发令牌，按角色跳转对应首页 |
| 路由权限控制 | 未登录访问管理端跳转登录页；双端路由按角色隔离 |
| AI 流式对话 | SSE 逐字接收大模型回复，支持“正在回复”状态与请求中断 |
| 会话管理 | 新建会话、历史列表分页、会话详情加载、删除会话 |
| 消息渲染 | AI 回复按 Markdown 渲染（标题、列表、加粗、代码块） |
| 情绪花园 | 展示当前会话识别出的主情绪、情绪分值（0–100）与正负性 |
| 情绪强度可视化 | 三档强度点阵与风险等级文案（正常 / 关注 / 预警 / 危机） |
| 个性化建议 | 针对当前情绪的建议文案与 2–3 条可执行的调节行动 |
| 风险提示卡 | 负面情绪且风险等级 ≥ 2 时展示安抚提示与求助指引 |
| 情绪日志 | 录入日期、情绪评分（1–10）、主导情绪（8 类）、触发因素、感想、睡眠质量与压力水平 |
| 知识文章 | 分页列表、分类与关键词检索、富文本详情、阅读量自增、热门推荐 |

### 管理端

| 功能 | 说明 |
| --- | --- |
| 数据看板 | 核心指标卡、情绪趋势折线图、会话统计分析、用户活跃度趋势（ECharts） |
| 文章管理 | 分页组合查询、新增与编辑、封面上传、发布 / 下线 / 删除状态流转、分类管理 |
| 咨询记录 | 会话记录列表、弹窗查看完整对话、按用户与时间检索 |
| 情绪日志管理 | 日志列表、详情与 AI 分析结果查看、无效日志删除 |
| 风险预警 | 关键词 + 语义双通道识别、四级风险分级、预警列表、高危转介工单、处理登记与统计 |

### 公共模块

- **统一认证鉴权**：JWT 签发与解析，拦截器校验令牌，接口按角色鉴权
- **统一响应与异常处理**：`Result{code, msg, data}` 三段结构，全局异常捕获
- **文件上传服务**：图片上传、类型与大小校验、静态资源访问
- **数据分页**：统一 `records` / `total` 结构，与前端分页组件对齐
- **隐私保护**：手机号、邮箱管理端脱敏展示，密码加盐哈希（BCrypt）存储

## 二、技术栈

### 总体架构

采用前后端分离的分层架构，自上而下分为表现层、接口层、业务层、数据层与外部服务层，由 Nginx 统一提供静态资源托管与接口反向代理。

| 层次 | 职责 | 主要技术 |
| --- | --- | --- |
| 表现层 | 用户端与管理端单页应用 | Vue 3 + Vite + Element Plus + Pinia + Vue Router |
| 接口层 | 路由分发、参数校验、统一响应、令牌校验 | Spring MVC + 拦截器 + `@RestControllerAdvice` |
| 业务层 | 认证、会话、情绪分析、风险分级、内容管理、统计 | Spring Service + 事务管理 |
| 数据层 | ORM、分页、逻辑删除、统计聚合查询 | MyBatis-Plus + MySQL 8 |
| 外部服务层 | 对话生成与情绪识别的模型调用 | 大模型开放平台 API + OkHttp |
| 部署层 | 静态资源托管、接口反向代理 | Nginx + Spring Boot 内嵌 Tomcat |

### 本仓库前端技术清单

| 技术 | 版本 | 用途 |
| --- | --- | --- |
| Vue | 3.5 | 视图层与组合式 API 组件化开发 |
| Vite | 7.x | 开发服务器与生产构建（`@` 指向 `src`） |
| Element Plus | 2.13 | 表格、表单、弹窗、分页等后台组件 |
| Pinia | 3.x | 全局状态管理 |
| Vue Router | 4.x | 双端路由与基于角色的前置守卫 |
| Axios | 1.x | HTTP 请求封装，拦截器统一注入令牌 |
| ECharts | 6.x | 情绪趋势、会话统计图表 |
| wangEditor | 5.x | 文章正文富文本编辑 |
| fetch-event-source | 2.x | SSE 流式请求客户端（支持 POST 与主动中断） |
| Sass | 1.x | 样式预处理 |

> 后端为 Spring Boot 3.3 + JDK 17 + MyBatis-Plus + MySQL 8 + JWT + Knife4j，AI 能力对接 DeepSeek / 通义千问 API；本仓库仅包含前端部分。

### 关键技术实现

1. **流式对话链路**：前端通过 `fetch-event-source` 向 `/api/psychological-chat/stream` 发起 POST 请求，后端以 `SseEmitter` 建立长连接逐块转发模型 token，结束时发送 `done` 事件，前端追加到消息气泡实现打字机效果。
2. **情绪结构化输出**：提示词要求模型返回包含主情绪、情绪分值、正负性、风险等级、建议文案与行动列表的 JSON，反序列化失败时降级为默认值并记录日志。
3. **风险分级规则**：关键词命中与语义判断双通道，最终等级取两者较大值，分为 0 正常 / 1 关注 / 2 预警 / 3 危机；等级 ≥ 2 展示提示卡，等级为 3 触发高危转介并生成工单。
4. **认证与权限控制**：登录签发含用户标识与角色的 JWT，前端拦截器注入令牌、路由守卫按角色分流，后端拦截器统一校验并做接口级角色校验，双重防护。
5. **数据可视化**：统计接口按日期分组聚合情绪分与会话量，ECharts 渲染折线图与柱状图，兼容空数据与单点数据。

## 四、快速开始

### 环境要求

- Node.js 18+（建议 20+）
- npm

### 安装与运行

```bash
cd ai-vue
npm install          # 安装依赖
npm run dev          # 启动开发服务器（默认 http://localhost:5173）
npm run build        # 生产构建，输出至 dist/
npm run preview      # 预览构建产物
```

### 接口代理

开发环境通过 Vite 代理将 `/api` 转发至后端服务（[vite.config.js](ai-vue/vite.config.js)）：

```js
server: {
  proxy: {
    '/api': {
      target: 'http://159.75.169.224:1235',
      changeOrigin: true,
    }
  }
}
```

文件访问基础地址配置于 [src/config/index.js](ai-vue/src/config/index.js)。后端服务需另行部署；本地联调时修改 `target` 为你的后端地址即可。

### 账号角色

- **普通用户**：自助注册，进入用户端
- **管理员**：由后端预置，登录后进入 `/back` 管理端
